# Python Bank ATM System

This is a simple Bank ATM project made using Python.

I made this project to practice Object-Oriented Programming concepts in Python. It has basic ATM operations like login, checking balance, depositing and withdrawing money, changing PIN and checking transaction history.

## Features

- Login using account number and PIN
- Check account balance
- Deposit money
- Withdraw money
- View transaction history
- Change PIN
- Add interest for Savings Account
- Savings Account and Current Account
- Logout option

## OOP Concepts Used

- Classes and Objects
- Encapsulation
- Inheritance
- Method Overriding
- Constructors
- Private attributes

Make sure Python is installed on your system.

Run the program using:

python bank.py
